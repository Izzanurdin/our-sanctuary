Folder Foto Profil (Avatars)
==============================
Silakan taruh foto profil kalian berdua di dalam folder ini:

1. Foto Sayang -> Beri nama: "sayang.jpg"  (atau "sayang.png")
2. Foto Izza   -> Beri nama: "izza.jpg"    (atau "izza.png")

Tips:
- Gunakan foto dengan rasio 1:1 (kotak/persegi) atau portrait wajah agar hasil tampilan maksimal.
- Format file yang didukung: .jpg, .jpeg, .png, .webp
- Jika foto belum dimasukkan, aplikasi akan otomatis menampilkan ikon hati & bintang yang estetik.
